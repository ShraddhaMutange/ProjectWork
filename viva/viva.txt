Basic HTML Questions
Q1. What is HTML?
HTML stands for HyperText Markup Language. 
It is used to create the structure of web pages.

Q2. What are HTML tags?
Tags are predefined keywords enclosed in angle brackets used to define webpage elements. 
Example:
<h1>Hello</h1>
<p>Paragraph</p>

Q3. Difference between HTML and HTML5? 
HTML	HTML5

Semantic tags clearly describe their meaning.

<section>
<footer>
<article>

Q5. Difference between div and span?
